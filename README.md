# CPE-and-Other-Practice
CPE 程式設計檢定練習與題解與其他練習題練習

### 1. 3n+1
* 2026/7/10完成
* **程式運作說明** :
*   **輸入** : 每行輸入包含兩個正整數 `i` 和 `j` ， 程式會持續讀取直到檔案結束（EOF），所以我用 while 來輸入。
*   **輸出** : 對應每組輸入，依序輸出原始的 `i` 和 `j` 以及該區間內的最大循環長度 ， 數值間以空格分隔並換行。

### 2. Odd_Sum
* 2026/7/10完成
* **程式運作說明** :
*   **輸入** : 輸入的第一列有一個整數 `t` (1<=t<=100)， 代表以下有多少組測試資料 。 每組測試資料為兩列，包含兩個數 `a` 和 `b`。(0<=a<=b<=100)
*   **輸出** : 每組測試資料輸出一列，內容為 `a`及 `b 間所有奇數的和。

### 3. Binary
* 2026/7/27完成
* **程式運作說明** :
*   **輸入** : 輸入若干行直到 EOF 為止。每一行包含一個十進位的整數。
*   **輸出** : 針對每一行的整數輸出其二進位制的結果。

### 4. Armstrong number
* 2026/9/9完成
* 所謂 Armstrong number 指的是一個 n 位數的整數，它的所有位數的 n 次方和恰好等於自己。
* **程式運作說明** :
*   **輸入** : 輸入共一行包含兩個數字n, m(n<m, n>0, m<=1000000)，代表所有尋找 armstrong number 的範圍。
*   **輸出** : 將所有範圍內的 armstrong number 依序由小到大輸出，如果沒有找到請輸出 none。

### 5. palindrome
* 2026/9/9完成
* **程式運作說明** :
*   **輸入** : 輸入資料共一行包含一個字串(長度 < 1000)。
*   **輸出** : 針對每一行輸入字串輸出 yes or no。

*   **輸出** : 輸出翻轉過後的數字。

### 7. a215.明明愛數數
* 2026/9/11完成
* **程式運作說明** :
*   **輸入** : 輸入以 EOF 結束。每一筆測試資料有兩個數字，分別為 n 和 m，其中 m-n 不會超過 10^5。。
*   **輸出** : 從 n 開始數，下一個數字是 n+1，再下一個數字是 n+2，以此類推。數了幾個數字之後，他數過的這些數字的總和會超過 m。
